## Projets Principaux

* **Projets de Jeux Vidéo (Unity / C#)** : Lead Dev du projet de fan-game "Yo-kai Watch 5" depuis février 2025.
* **Site Web "[Wikinyan](https://wikinyan.com/)" (HTML / CSS / JS / Python)** : Création d'un site encyclopédique sur l'univers de *Yo-kai Watch* permettant chaque jour à plus de 1 000 visiteurs différents de trouver des réponses à leurs questions.
* **Site Web "[La Plume Numérique](https://www.laplumenumerique.com/)" (HTML / CSS / JS)** : Développement d'un site web de publication mensuelle d'histoires et de bandes dessinées.
* **Refonte du site de l'association [DFD](https://dyspraxies-france-dys.web.app/) (HTML / CSS / JS)** : Refonte et modernisation du site internet de l'association *Dyspraxie France Dys* (Dyspraxies.fr) pour leur offrir une plateforme moderne et flexible.
* **Jeu Web "[Cours Ken](https://cours-ken.web.app/)" (HTML / CSS / JS)** : Réalisation d'un jeu vidéo jouable directement sur navigateur mettant en avant les personnages d'une bande dessinée.
* **[Cours de programmation](https://lnkd.in/p/eAewQu7h) (Unity / C#)** : Dispensation de cours de programmation individuels chaque samedi pour initier des collégiens et lycéens à la création de jeux vidéo.
* **API "[Yo-kai API](https://github.com/Emerick2/yo-kai-API)" (Python / JSON)** : Conception d'une API complète dédiée à la franchise *Yo-kai Watch* afin de faciliter le développement de fan-games et de projets communautaires.
